Data Analytics Project

Overview

This project focuses on analyzing customer data to identify useful business insights and trends.

The project covers the complete data analytics workflow, starting from data loading and cleaning to SQL analysis, Power BI visualization, reporting, and presentation.

Dataset

The dataset contains customer shopping and behavioral information.

The data was analyzed to understand:

- Customer behavior
- Purchase patterns
- Product and category performance
- Sales trends
- Customer demographics
- Key business insights

Tools & Technologies

- Python – Data loading, cleaning, and EDA
- Pandas – Data manipulation
- Jupyter Notebook – Data analysis
- SQL – Data querying and analysis
- PostgreSQL / MySQL / SQL Server – Database analysis
- Power BI – Dashboard and visualization
- Gamma – Project presentation
- MS Excel – Data inspection and supporting analysis

Project Steps

1. Load Data

Loaded the dataset into Python using Pandas.

2. Exploratory Data Analysis (EDA)

Performed EDA to understand:

- Dataset structure
- Missing values
- Duplicate records
- Data types
- Numerical and categorical columns
- Basic statistical information
- Data patterns and trends

3. Data Cleaning

Cleaned the dataset by:

- Handling missing values
- Removing duplicate records
- Correcting data types
- Checking inconsistent values
- Preparing the data for analysis

4. SQL Analysis

Loaded the cleaned data into SQL and performed queries to answer business-related questions.

Examples:

- Total sales
- Average purchase amount
- Customer count
- Category-wise performance
- Customer segmentation
- Purchase trends
- Top-performing products

5. Power BI Dashboard

Created an interactive Power BI dashboard to present important findings through charts, graphs, KPIs, and filters.

6. Report

Prepared a project report explaining:

- Data preparation
- Analysis process
- SQL queries
- Dashboard insights
- Key findings

7. Presentation

Created a project presentation using Gamma to explain the project, analysis, dashboard, and results.

Dashboard

The Power BI dashboard provides an interactive view of the analyzed data.

Key dashboard components include:

- Interactive filters and slicers

The analysis helped identify important patterns in customer behavior, purchasing trends, and product/category performance.

How to Run

Step 1: Clone the Repository

git clone <your-github-repository-link>

Step 2: Open the Jupyter Notebook

Open the ".ipynb" file in Jupyter Notebook or JupyterLab.

Step 3: Install Required Libraries

pip install pandas numpy matplotlib seaborn sqlalchemy

Step 4: Load the Dataset

Place the dataset in the project folder and update the file path in the notebook.

Step 5: Run the Analysis

Run the notebook cells in order to perform data loading, EDA, and data cleaning.

Step 6: Run SQL Analysis

Load the cleaned dataset into PostgreSQL, MySQL, or SQL Server and execute the SQL queries provided in the project.

Step 7: Open the Power BI Dashboard

Open the Power BI ".pbix" file to view the interactive dashboard.
